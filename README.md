# Kopuz-org Tap

## How do I install these formulae?

`brew install kopuz-org/tap/<formula>`

Or `brew tap kopuz-org/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "kopuz-org/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
